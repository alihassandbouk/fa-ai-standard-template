## Persistence/DatabaseOptions.cs

```csharp
using System.ComponentModel.DataAnnotations;

namespace Catalog.Infrastructure.Persistence;

/// <summary>
/// EF Core / SQL Server settings bound from the <c>Database</c> section of appsettings.
/// </summary>
public sealed class DatabaseOptions
{
    /// <summary>The configuration section name.</summary>
    public const string SectionName = "Database";

    /// <summary>Gets the SQL command timeout in seconds.</summary>
    [Range(1, 600)]
    public int CommandTimeoutSeconds { get; init; } = 30;

    /// <summary>Gets the maximum number of transient-failure retries.</summary>
    [Range(0, 10)]
    public int MaxRetryCount { get; init; } = 5;

    /// <summary>Gets the maximum delay between retries in seconds.</summary>
    [Range(1, 60)]
    public int MaxRetryDelaySeconds { get; init; } = 10;

    /// <summary>Gets a value indicating whether parameter values are included in logs. Development only.</summary>
    public bool EnableSensitiveDataLogging { get; init; }

    /// <summary>Gets a value indicating whether detailed query errors are enabled. Development only.</summary>
    public bool EnableDetailedErrors { get; init; }

    /// <summary>Gets a value indicating whether pending migrations are applied at startup.</summary>
    public bool ApplyMigrationsOnStartup { get; init; }

    /// <summary>Gets the maximum number of pooled DbContext instances (AddDbContextPool).</summary>
    [Range(16, 4096)]
    public int DbContextPoolSize { get; init; } = 128;
}
```

> Connection pooling has two layers, and both must be on. ADO.NET pools the SQL connections: `Pooling=True`, `Min Pool Size` and `Max Pool Size` in the connection string. EF Core pools the `DbContext` instances with `AddDbContextPool`, sized by `DbContextPoolSize`. The 30-second timeout is also set in two places: `CommandTimeoutSeconds` for queries and `Connect Timeout=30` in the connection string for opening connections.

## Persistence/AppDbContext.cs

```csharp
using Catalog.Domain.Categories;
using Catalog.Domain.Common;
using Catalog.Domain.Products;
using Catalog.Infrastructure.Persistence.Configurations;
using Microsoft.EntityFrameworkCore;

namespace Catalog.Infrastructure.Persistence;

/// <summary>
/// The application's EF Core database context and unit of work.
/// </summary>
/// <param name="options">The context options configured in DI.</param>
public sealed class AppDbContext(DbContextOptions<AppDbContext> options) : DbContext(options), IUnitOfWork
{
    /// <summary>Gets the products set.</summary>
    public DbSet<Product> Products => Set<Product>();

    /// <summary>Gets the categories set.</summary>
    public DbSet<Category> Categories => Set<Category>();

    /// <inheritdoc />
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // Applies only this context's configurations. View mappings for ReadOnlyDbContext live in another namespace.
        modelBuilder.ApplyConfigurationsFromAssembly(
            typeof(AppDbContext).Assembly,
            type => type.Namespace == typeof(ProductConfiguration).Namespace);
        base.OnModelCreating(modelBuilder);
    }
}
```

> `DbContext.SaveChangesAsync(CancellationToken)` implicitly satisfies `IUnitOfWork`.

## Persistence/Interceptors/AuditableEntityInterceptor.cs

```csharp
using Catalog.Domain.Common;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Diagnostics;

namespace Catalog.Infrastructure.Persistence.Interceptors;

/// <summary>
/// Stamps <see cref="BaseEntity.CreatedAtUtc"/> and <see cref="BaseEntity.UpdatedAtUtc"/> before saving.
/// </summary>
/// <param name="timeProvider">The clock abstraction.</param>
public sealed class AuditableEntityInterceptor(TimeProvider timeProvider) : SaveChangesInterceptor
{
    private readonly TimeProvider _timeProvider = timeProvider ?? throw new ArgumentNullException(nameof(timeProvider));

    /// <inheritdoc />
    public override InterceptionResult<int> SavingChanges(DbContextEventData eventData, InterceptionResult<int> result)
    {
        ApplyAudit(eventData.Context);
        return base.SavingChanges(eventData, result);
    }

    /// <inheritdoc />
    public override ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData eventData,
        InterceptionResult<int> result,
        CancellationToken cancellationToken = default)
    {
        ApplyAudit(eventData.Context);
        return base.SavingChangesAsync(eventData, result, cancellationToken);
    }

    private void ApplyAudit(DbContext? context)
    {
        if (context is null)
        {
            return;
        }

        var now = _timeProvider.GetUtcNow().UtcDateTime;

        foreach (var entry in context.ChangeTracker.Entries<BaseEntity>())
        {
            if (entry.State == EntityState.Added)
            {
                entry.Property(e => e.CreatedAtUtc).CurrentValue = now;
            }
            else if (entry.State == EntityState.Modified)
            {
                entry.Property(e => e.UpdatedAtUtc).CurrentValue = now;
            }
        }
    }
}
```

## Persistence/Configurations (entity mapping)

```csharp
using Catalog.Domain.Products;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

namespace Catalog.Infrastructure.Persistence.Configurations;

/// <summary>
/// EF Core mapping for <see cref="Product"/>.
/// </summary>
public sealed class ProductConfiguration : IEntityTypeConfiguration<Product>
{
    /// <inheritdoc />
    public void Configure(EntityTypeBuilder<Product> builder)
    {
        builder.ToTable("Products");

        builder.HasKey(p => p.Id);
        builder.Property(p => p.Id).UseIdentityColumn();

        builder.Property(p => p.Name).HasMaxLength(200).IsRequired();
        builder.Property(p => p.Sku).HasMaxLength(50).IsRequired();
        builder.Property(p => p.Description).HasMaxLength(2000);
        builder.Property(p => p.Price).HasPrecision(18, 2);
        // No HasDefaultValue(true) on bool: EF would treat 'false' as "unset" and insert the DB default.
        builder.Property(p => p.IsActive).IsRequired();
        builder.Property(p => p.CreatedAtUtc).IsRequired();

        builder.HasIndex(p => p.Sku).IsUnique();
        builder.HasIndex(p => p.CategoryId);

        builder.HasOne(p => p.Category)
            .WithMany(c => c.Products)
            .HasForeignKey(p => p.CategoryId)
            .OnDelete(DeleteBehavior.Restrict);
    }
}
```

## Persistence/Repositories/Repository.cs (base repository)

Every method that touches the database runs through `DataAccessGuard` (defined in [read-only-views.md](read-only-views.md)). It logs provider failures with context and rethrows them as `DataAccessException`, which the API maps to 503. `Update` and `Remove` only change tracker state, so they need only argument validation.

```csharp
using System.Linq.Expressions;
using Catalog.Domain.Common;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;

namespace Catalog.Infrastructure.Persistence.Repositories;

/// <summary>
/// EF Core implementation of <see cref="IRepository{TEntity}"/>. Entity repositories derive from this class.
/// </summary>
/// <typeparam name="TEntity">The entity type.</typeparam>
/// <param name="context">The database context.</param>
/// <param name="loggerFactory">The logger factory.</param>
public class Repository<TEntity>(AppDbContext context, ILoggerFactory loggerFactory) : IRepository<TEntity>
    where TEntity : BaseEntity
{
    /// <summary>Gets the database context.</summary>
    protected AppDbContext Context { get; } = context ?? throw new ArgumentNullException(nameof(context));

    /// <summary>Gets the logger for this repository.</summary>
    protected ILogger Logger { get; } =
        (loggerFactory ?? throw new ArgumentNullException(nameof(loggerFactory))).CreateLogger(typeof(TEntity).Name + "Repository");

    /// <summary>Gets the entity set.</summary>
    protected DbSet<TEntity> DbSet => Context.Set<TEntity>();

    /// <inheritdoc />
    public virtual Task<TEntity?> GetByIdAsync(int id, CancellationToken cancellationToken = default) =>
        ExecuteAsync(() => DbSet.FindAsync([id], cancellationToken).AsTask(), nameof(GetByIdAsync));

    /// <inheritdoc />
    public virtual Task<IReadOnlyList<TEntity>> GetAllAsync(CancellationToken cancellationToken = default) =>
        ExecuteAsync<IReadOnlyList<TEntity>>(
            async () => await DbSet.AsNoTracking().ToListAsync(cancellationToken).ConfigureAwait(false),
            nameof(GetAllAsync));

    /// <inheritdoc />
    public virtual Task<IReadOnlyList<TEntity>> FindAsync(
        Expression<Func<TEntity, bool>> predicate,
        CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(predicate);
        return ExecuteAsync<IReadOnlyList<TEntity>>(
            async () => await DbSet.AsNoTracking().Where(predicate).ToListAsync(cancellationToken).ConfigureAwait(false),
            nameof(FindAsync));
    }

    /// <inheritdoc />
    public virtual Task<bool> AnyAsync(
        Expression<Func<TEntity, bool>> predicate,
        CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(predicate);
        return ExecuteAsync(() => DbSet.AnyAsync(predicate, cancellationToken), nameof(AnyAsync));
    }

    /// <inheritdoc />
    public virtual Task<int> CountAsync(
        Expression<Func<TEntity, bool>>? predicate = null,
        CancellationToken cancellationToken = default) =>
        ExecuteAsync(
            () => predicate is null ? DbSet.CountAsync(cancellationToken) : DbSet.CountAsync(predicate, cancellationToken),
            nameof(CountAsync));

    /// <inheritdoc />
    public virtual async Task AddAsync(TEntity entity, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(entity);
        // Change-tracker only (no SQL is sent until SaveChangesAsync), so no DataAccessGuard is needed.
        await DbSet.AddAsync(entity, cancellationToken).ConfigureAwait(false);
    }

    /// <inheritdoc />
    public virtual void Update(TEntity entity)
    {
        ArgumentNullException.ThrowIfNull(entity);
        DbSet.Update(entity);
    }

    /// <inheritdoc />
    public virtual void Remove(TEntity entity)
    {
        ArgumentNullException.ThrowIfNull(entity);
        DbSet.Remove(entity);
    }

    /// <summary>Runs a database call through <see cref="DataAccessGuard"/>.</summary>
    /// <typeparam name="T">The result type.</typeparam>
    /// <param name="operation">The database call.</param>
    /// <param name="operationName">The calling method name.</param>
    /// <returns>The result.</returns>
    protected Task<T> ExecuteAsync<T>(Func<Task<T>> operation, string operationName) =>
        DataAccessGuard.ExecuteAsync(operation, Logger, typeof(TEntity).Name, operationName);
}
```

## Entity repositories

```csharp
using Catalog.Domain.Products;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;

namespace Catalog.Infrastructure.Persistence.Repositories;

/// <summary>
/// EF Core implementation of <see cref="IProductRepository"/>.
/// </summary>
/// <param name="context">The database context.</param>
/// <param name="loggerFactory">The logger factory.</param>
public sealed class ProductRepository(AppDbContext context, ILoggerFactory loggerFactory)
    : Repository<Product>(context, loggerFactory), IProductRepository
{
    /// <inheritdoc />
    public Task<Product?> GetBySkuAsync(string sku, CancellationToken cancellationToken = default)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(sku);
        var normalized = sku.Trim().ToUpperInvariant();
        return ExecuteAsync(
            () => DbSet.AsNoTracking().FirstOrDefaultAsync(p => p.Sku == normalized, cancellationToken),
            nameof(GetBySkuAsync));
    }

    /// <inheritdoc />
    public Task<Product?> GetWithCategoryAsync(int id, CancellationToken cancellationToken = default) =>
        ExecuteAsync(
            () => DbSet.AsNoTracking()
                .Include(p => p.Category)
                .FirstOrDefaultAsync(p => p.Id == id, cancellationToken),
            nameof(GetWithCategoryAsync));

    /// <inheritdoc />
    public Task<(IReadOnlyList<Product> Items, int TotalCount)> GetPagedAsync(
        int pageNumber,
        int pageSize,
        int? categoryId,
        CancellationToken cancellationToken = default)
    {
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(pageNumber);
        ArgumentOutOfRangeException.ThrowIfNegativeOrZero(pageSize);

        return ExecuteAsync<(IReadOnlyList<Product>, int)>(async () =>
        {
            var query = DbSet.AsNoTracking();

            if (categoryId.HasValue)
            {
                query = query.Where(p => p.CategoryId == categoryId.Value);
            }

            var totalCount = await query.CountAsync(cancellationToken).ConfigureAwait(false);

            var items = await query
                .Include(p => p.Category)
                .OrderBy(p => p.Name)
                .ThenBy(p => p.Id)
                .Skip((pageNumber - 1) * pageSize)
                .Take(pageSize)
                .ToListAsync(cancellationToken)
                .ConfigureAwait(false);

            return (items, totalCount);
        }, nameof(GetPagedAsync));
    }
}
```

## Persistence/MigrationExtensions.cs

```csharp
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;

namespace Catalog.Infrastructure.Persistence;

/// <summary>
/// Applies pending EF Core migrations at startup when enabled in configuration.
/// </summary>
public static class MigrationExtensions
{
    /// <summary>Applies pending migrations if <see cref="DatabaseOptions.ApplyMigrationsOnStartup"/> is true.</summary>
    /// <param name="services">The root service provider.</param>
    /// <param name="cancellationToken">A token to cancel the operation.</param>
    public static async Task ApplyMigrationsAsync(this IServiceProvider services, CancellationToken cancellationToken = default)
    {
        await using var scope = services.CreateAsyncScope();
        var options = scope.ServiceProvider.GetRequiredService<IOptions<DatabaseOptions>>().Value;
        if (!options.ApplyMigrationsOnStartup)
        {
            return;
        }

        var logger = scope.ServiceProvider.GetRequiredService<ILoggerFactory>().CreateLogger(nameof(MigrationExtensions));
        var context = scope.ServiceProvider.GetRequiredService<AppDbContext>();

        var pending = (await context.Database.GetPendingMigrationsAsync(cancellationToken).ConfigureAwait(false)).ToList();
        if (pending.Count == 0)
        {
            logger.LogInformation("Database is up to date; no pending migrations");
            return;
        }

        logger.LogInformation("Applying {Count} pending migrations: {Migrations}", pending.Count, pending);
        await context.Database.MigrateAsync(cancellationToken).ConfigureAwait(false);
        logger.LogInformation("Database migrations applied successfully");
    }
}
```

> In production, prefer applying migrations from the deployment pipeline (`dotnet ef migrations script --idempotent` or `dotnet ef migrations bundle`) and keep `ApplyMigrationsOnStartup` set to `false`.

## DependencyInjection.cs

```csharp
using Catalog.Domain.Categories;
using Catalog.Domain.Common;
using Catalog.Domain.Products;
using Catalog.Infrastructure.Persistence;
using Catalog.Infrastructure.Persistence.Interceptors;
using Catalog.Infrastructure.Persistence.Repositories;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Options;

namespace Catalog.Infrastructure;

/// <summary>
/// Registers Infrastructure services (EF Core, repositories, unit of work).
/// </summary>
public static class DependencyInjection
{
    /// <summary>Adds Infrastructure services to the container.</summary>
    /// <param name="services">The service collection.</param>
    /// <param name="configuration">The application configuration.</param>
    /// <returns>The same service collection for chaining.</returns>
    /// <exception cref="InvalidOperationException">Thrown when the connection string is missing.</exception>
    public static IServiceCollection AddInfrastructure(this IServiceCollection services, IConfiguration configuration)
    {
        ArgumentNullException.ThrowIfNull(configuration);

        services.AddOptions<DatabaseOptions>()
            .Bind(configuration.GetSection(DatabaseOptions.SectionName))
            .ValidateDataAnnotations()
            .ValidateOnStart();

        var connectionString = configuration.GetConnectionString("DefaultConnection")
            ?? throw new InvalidOperationException("Connection string 'DefaultConnection' is not configured.");

        // The pool size must be known at registration time, so read it directly from configuration.
        var dbPoolSize = configuration.GetSection(DatabaseOptions.SectionName).Get<DatabaseOptions>()?.DbContextPoolSize ?? 128;

        services.AddSingleton(TimeProvider.System);

        // Pooled contexts require singleton interceptors (this one only depends on TimeProvider).
        services.AddSingleton<AuditableEntityInterceptor>();

        // DbContext pooling plus ADO.NET connection pooling (Pooling/Min/Max Pool Size in the connection string).
        services.AddDbContextPool<AppDbContext>((serviceProvider, options) =>
        {
            var db = serviceProvider.GetRequiredService<IOptions<DatabaseOptions>>().Value;

            options.UseSqlServer(connectionString, sql =>
            {
                sql.MigrationsAssembly(typeof(AppDbContext).Assembly.FullName);
                sql.CommandTimeout(db.CommandTimeoutSeconds);
                sql.EnableRetryOnFailure(db.MaxRetryCount, TimeSpan.FromSeconds(db.MaxRetryDelaySeconds), errorNumbersToAdd: null);
            });

            options.AddInterceptors(serviceProvider.GetRequiredService<AuditableEntityInterceptor>());

            // Full EF Core logging flows through the host ILoggerFactory (Serilog).
            // SQL verbosity is controlled by the Serilog overrides in appsettings.
            options.EnableDetailedErrors(db.EnableDetailedErrors);
            options.EnableSensitiveDataLogging(db.EnableSensitiveDataLogging);
        }, poolSize: dbPoolSize);

        // If the app reads SQL Server views, also register ReadOnlyDbContext, IAuditLogger and the
        // view repositories here. See read-only-views.md.

        services.AddScoped<IUnitOfWork>(sp => sp.GetRequiredService<AppDbContext>());

        services.AddScoped(typeof(IRepository<>), typeof(Repository<>));
        services.AddScoped<IProductRepository, ProductRepository>();
        services.AddScoped<ICategoryRepository, CategoryRepository>();

        return services;
    }
}
```

> With `EnableRetryOnFailure`, wrap any manual transaction (`BeginTransactionAsync`) in `context.Database.CreateExecutionStrategy().ExecuteAsync(...)`. Otherwise EF throws.

## Migrations: commands

Install the tool once with `dotnet tool install --global dotnet-ef`. Then run these from the solution root. When `ReadOnlyDbContext` also exists, add `--context AppDbContext` to every command:

```bash
# Create a migration
dotnet ef migrations add InitialCreate \
  --project src/Catalog.Infrastructure \
  --startup-project src/Catalog.Api \
  --output-dir Persistence/Migrations

# Apply to the database in appsettings (ASPNETCORE_ENVIRONMENT selects the file)
dotnet ef database update --project src/Catalog.Infrastructure --startup-project src/Catalog.Api

# Remove the last unapplied migration
dotnet ef migrations remove --project src/Catalog.Infrastructure --startup-project src/Catalog.Api

# Idempotent SQL script for deployment pipelines
dotnet ef migrations script --idempotent --output artifacts/migrations.sql \
  --project src/Catalog.Infrastructure --startup-project src/Catalog.Api
```

The design-time tools build the Api host, so they read the connection string from the Api's appsettings. No `IDesignTimeDbContextFactory` is needed.
